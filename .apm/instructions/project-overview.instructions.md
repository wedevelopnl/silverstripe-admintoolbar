# Project Overview

Silverstripe Admin Toolbar — a frontend toolbar for CMS users: page actions (edit, unpublish, archive), the CMS main menu, a user menu, cache flush, and query/timing diagnostics.

Package: `wedevelopnl/silverstripe-admintoolbar` (type: `silverstripe-vendormodule`)

## Requirements

- PHP ^8.3
- `silverstripe/framework` ^6.0, `silverstripe/cms` ^6.0, `silverstripe/admin` ^3.0, `silverstripe/versioned` ^3.0, `silverstripe/vendor-plugin` ^3.0
- Optional: `wedevelopnl/silverstripe-grid` (Grid menu); conflicts with grid `<6.0.0-beta.4`
